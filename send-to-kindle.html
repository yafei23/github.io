工作原理

  1. 提交后会打开一个预填好链接的 GitHub Issue，确认创建即可；
  2. GitHub Actions 抓取文章、用 Readability 提取正文并打包成 EPUB；
  3. 通过 SMTP 发送到你的 @kindle.com 邮箱，随后自动关闭 Issue。
  4. 首次使用需要配置仓库 Secrets，见 配置说明。
